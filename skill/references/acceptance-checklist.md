# 验收清单（主 agent 在 seal 之前自己过一遍）

seal 之后就不能改了。这份清单是 seal 前的最后一道门。
**任何一条不过，就不要 seal，先让执行者补。**

## 1. 文件层：产物真的存在

```powershell
$v = "<项目>\v003"
Get-ChildItem $v -Recurse -File | Select-Object FullName, Length | Sort-Object FullName
```

- [ ] `plan.md` 有，且是本轮改过的那一版（不是上一轮的复制）
- [ ] `code/` 下有可运行脚本（不是空文件、不是 TODO 占位）
- [ ] `results/` 下每个表都在，大小 > 0
- [ ] `figures/` 下 PNG 与 PDF 成对，PNG 不是 1 KB 的占位图
- [ ] `results/RUNLOG.md` 有，且含 n、剔除明细、软件版本、警告原文
- [ ] **RUNLOG 的版本归属正确**：标题/路径写的是本版本，或首行明写"承接自 vNNN、未在本版重跑"。
      承接来的 RUNLOG 如果还写着上一版路径，溯源就是假的（复审必被打回）
- [ ] **表注有载体**：结果表若要求表注口径（禁绝对换算、平均斜率、合成数据声明等），
      `results/` 下要有 `.md` 渲染件承载它；CSV 装不下表注，光在 `plan.md` 里写口径等于没写
- [ ] 文件时间戳在本轮内（旧时间戳可能是没重跑）

## 2. 数字层：数字自洽

- [ ] 每个效应量都有点估计 + 95%CI（只有 p 值 = 不合格）
- [ ] `n` 在三处一致：`RUNLOG.md`、结果 csv、图注
- [ ] 剔除明细相加 = 原始 n − 分析 n（对不上就是漏了剔除原因）
- [ ] CI 与 p 值方向不矛盾（CI 跨 1 却 p<0.05 = 算错了）
- [ ] 抽查一个 OR 手算：`exp(beta)` 与表里的 OR 一致
- [ ] 分类变量参照组写清楚了（表里 `term` 命名能看出参照）

## 3. 图数一致

- [ ] 打开每张图看（`read_image`），不是只看代码
- [ ] 抽查 ≥3 个数据点：图内值 vs `results/` csv 值
- [ ] 轴标签含单位；对数轴标了 log；截断轴标了断轴
- [ ] 误差线类型（SE/SD/95%CI）写进图注
- [ ] 森林图有参考线；KM 有 number-at-risk；亚组有交互 p
- [ ] 图中 n 与 `RUNLOG.md` 一致

## 4. 代码层：能重跑

- [ ] 随机种子固定
- [ ] 路径参数化，没有写死的绝对路径（`grep -r "C:\\\\" code/` 应为空或仅注释）
- [ ] 没有 `suppressWarnings` / `try: ... except: pass` 吞掉错误
- [ ] 从 `data/` 原样重跑能出同样的表（至少跑一次主模型脚本验证）

## 5. 方案层：执行没有跑偏

- [ ] 变量定义（暴露、结局、协变量）与 `plan.md` 逐项对得上
- [ ] 调整集与方案一致，没有偷偷加减
- [ ] 方案里写了但没做的分析，在 `RUNLOG.md` 的 DEVIATIONS 里有说明
- [ ] 方案外多做的分析，已获主 agent 同意并记入版本说明

## 6. 留档层

- [ ] `epi_run.py status` 显示本版本未 seal，内容与预期一致
- [ ] 本轮 `next --note` 的说明写得能让三个月后的自己看懂改了什么

全部打勾 → `python scripts/epi_run.py seal --dir <项目>` → 送审。

## 常见被漏掉的坑

| 坑 | 后果 |
|---|---|
| 用上一轮的结果 csv 直接改名 | 图审时数字对不上，白跑一轮 |
| 只跑主模型，敏感性分析声称"做过" | 审稿人查无实据 → MAJOR |
| 图注里的 n 是原始 n，不是分析 n | 表述错误 → MINOR 起步 |
| 分类变量当连续变量进了模型 | 主模型结论错 → MAJOR，必须重跑 |
| 未声明缺失处理 | 审稿人无法复现 → MAJOR |
| seal 之后又改了 csv 没升版本 | `check` 报哈希不符，交付被拒 |
